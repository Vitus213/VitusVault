## 回答修补建议

### 必背：转账死锁问题标准答案

```
问题：A和B同时互相转账，如何避免死锁？

答案：按账户ID排序加锁。无论谁给谁转账，都先锁ID小的账户，再锁ID大的账户。
这样所有转账操作的加锁顺序一致，不会形成环路等待，从而避免死锁。

扩展：
- 分布式场景可用分布式锁，同样按ID排序
- 也可以用全局事务ID排序
- 银行实际可能用TCC或Saga模式
```

### 必背：为什么从操作系统转向业务开发

```
"操作系统开发让我对系统底层有深入理解——内存管理、并发控制、IO处理这些
在业务系统的高并发场景同样重要。我希望把这些底层能力应用到实际业务中，
解决真实的用户问题，看到自己的代码产生直接的业务价值。"
```
