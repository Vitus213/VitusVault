腾讯-WXG-后台开发-一面-问题整理


面试问题

一、项目与开源经历

1. 请你先做个简单的自我介绍。
2. 你是怎么开始加入这个开源社区的，背景是什么？
3. 现在这个社区是什么组织在运营它？
4. 这个系统现在已经有可用的版本了吗，还是还处在开发期？
5. 它是基于哪一个开源 OS 做的吗？
6. 这个系统的代码是不是基本都是 Rust 写的？
7. 你觉得用 Rust 写内核，相比用 C 来写，有什么比较好的地方？
8. 如果只是内存泄露的问题，你觉得“内存泄露”这个事情是选择编程语言的重大影响因素吗？
9. 你觉得 Rust 在实现高效算法时，和 C / C++ 相比，优势和劣势分别是什么？
10. 如果不考虑运行效率和内存效率，只看代码实现过程和后续维护，Rust 和 C / C++ 有没有高下之分？
11. 如果程序出现死锁或挂住，你通常会怎么定位、怎么调试？
12. 你在项目里调试时，日志和 GDB 一般怎么选，为什么？
13. DragonOS 这类系统工程一般是怎么组织编译的？
14. 如果让你自己去抽象一个编译系统，你会怎么描述这个构建过程？

二、AI 编程与工程认知

1. 你现在用什么 AI 来辅助写代码，用得多吗？
2. 你觉得 Agent 写的代码和你自己写的代码相比，有什么差异？
3. 你觉得你有能力去纠正 AI Agent 写出来的错误吗？
4. 你觉得要达到什么样的经验水平，才算有能力给 AI 做纠错？
5. 如果想在不故意误导模型的前提下，让大模型在编程环境里出现明显错误或幻觉，正常工作中什么情况可能触发？
6. 如果项目依赖的上下文非常大，超过模型窗口，大模型是不是更容易出现遗忘和幻觉？
7. 你觉得现在学生群体里，用 AI Agent 编程的比例大概是多少？怎样算“会用 AI 编程”？
8. 如果未来出现一门新的语言，而 Agent 比人更快学会，你觉得人应该怎么继续驾驭 Agent？

三、操作系统与并发基础

1. 简单讲一下进程和线程的区别。
2. CPU 调度是以进程为单位还是线程为单位？
3. 为什么在线程的基础上还要再设计协程？协程解决的核心问题是什么？
4. 如果大量并发时，为什么不用多进程，而要考虑多线程或协程？

四、C / C++ 与语言基础

1. Rust、C、C++ 这几门语言，按你的熟悉程度你会怎么排？
2. C++ 是怎么规避内存泄露问题的？
3. unique_ptr 和 shared_ptr 分别适用于哪些场景？为什么会有两种设计，而不是只保留一种？

五、学习方法与业务认知

1. 你平时一般怎么分配学习时间？
2. 你通常是怎么决定“学什么”，以及怎么学习一个新的方向的？
3. 你了解推荐系统吗？
4. 你平时会刷抖音、视频号这类短视频产品吗？
5. 你觉得抖音和微信视频号在产品体验上有什么差异？

六、算法题

1. 写一个 A × B 的大数乘法，输入是两个自然数，范围在 1000 位以内。

## 反问环节

1. 你们业务方面主要是负责微信视频号哪一块？
   - 推荐工程方向，主要做模型训练、推理，以及在线服务的维护和优化。

2. 您觉得我哪些地方还需要改进？
   - 目前阶段还有很多东西可以继续学，熟练度还有提升空间；有 AI Agent 辅助后，学习速度可以更快。
