面试问题

一、项目与AI实践

1. 先做一下自我介绍，讲一下学习情况和主要项目经历。
2. 大学过程中有接触过 AI 相关的课程吗？包括哪些？
3. 除了在项目里创建 AI 辅助开发的 skill 之外，还做过哪些 AI 相关的事情？比如大模型训练、微调、数据特征提取等？
4. 在 AI 辅助编码过程中，用的是什么工具和平台？例如 Claude、Copilot 等？
5. 平常用 Claude Code 的时候，如何使用？装了哪些插件？提示词是怎么维护的？整体架构是怎么设计和管理的？

二、容器 / Cgroup / 操作系统

6. 简单介绍一下容器相关的 cgroup 原理，它是怎么做到资源隔离的？利用了 Linux 的哪些能力？
7. 再讲讲 loop 设备子系统中状态机的实现思路，为什么要这样设计？

三、语言与并发基础（Rust / C++）

8. 简单介绍一下 Rust 里的生命周期和所有权的概念，各自解决了什么问题？
9. Box 这种结构（智能指针）的作用是什么？在什么场景下会用到？
10. 在一个实际编程场景中，如果要对智能指针里的内容做修改，同时要做并发控制，在多线程里如何保证内部数据不会被并发修改？
11. 简单讲讲 C++ 里的虚类 / 虚函数的作用是什么？底层大概是怎么实现的？
12. 指针和引用的区别是什么？在函数参数传递时有什么不同？

四、算法与手撕代码

13. 手写 LRU 缓存：在给定的模板代码基础上，实现 get / put 等接口，保证在缓存容量固定时，访问和更新都是 O(1)，并在 get 时更新最近使用顺序。
