字节-27届暑期-国际支付后端-一面-问题整理


面试问题

一、项目相关

1. 先做一下自我介绍。
2. 这个 OS 开源社区具体是做什么的？你能详细介绍一下吗？
3. 这个开源项目现在有哪些实际使用场景？有没有商业化或用户量级比较大的场景？
4. 这个社区是谁主导发起的？
5. 发一下 GitHub 项目链接和你的主页链接，我看一下你的贡献情况。
6. 选一个你最近的提交，讲讲里面的代码逻辑和核心改动。
7. 你这个 Cgroup 的数据结构和方法设计，主要参考了什么？是参考教材、Linux 还是自己设计的？
8. 你实现完之后，怎么验证这些代码的正确性？有没有做性能相关验证？
9. 你现在做的这些事情都偏操作系统方向，这个岗位其实偏业务研发，你为什么会投这个岗位？有没有投过操作系统相关岗位？
10. 你之前了解过支付相关业务吗？
11. 如果能实习的话，实习时长能保证多久？

二、操作系统

1. 什么是死锁？怎么避免？
2. 支付系统里一个经典场景：A 给 B 转账、B 同时给 A 转账，如果两个请求分别先锁住自己的账户，再去锁对方账户，就会死锁。你会怎么避免？
3. Linux 常见的进程状态有哪些？
4. 在 Linux 里，从键盘按下一个键到这个按键显示在屏幕上，大致经历了哪些操作？

三、中间件

1. MySQL、消息队列、Redis 这些中间件你有使用过吗？

四、计算机网络

1. 什么是 TCP 的慢启动？
2. 你再细说一下 TCP 的拥塞控制。
3. HTTP 和 HTTPS 的区别是什么？
4. TLS 加密握手的细节说一下。
5. 一个数据包从应用层产生到网卡发出的全过程是什么？

五、算法题

1. 三数之和：给定一个整数数组 nums，返回所有和为 0 且不重复的三元组。先讲思路、分析时间复杂度，再写代码并跑题目里的 case。

## 反问环节

1. 你觉得我还有哪些地方可以改进，或者有哪些地方还可以提高？
   - 代码熟练度这块需要提升，调试时间比较长。

2. 你们国际支付业务主要是负责什么？更偏延迟优化，还是偏基础设施？
   - 如果从大部门来看，国际支付负责字节所有海外业务的支付，包括 TikTok、小说、剪映海外版等，整体更像一个中台角色。
