# 操作系统八股

### 进程 线程 协程 
1. 进程 ： 运行中的程序叫作进程 ，上下文切换开销大，有独立虚拟内存空间 ，页表文件描述符，内核堆栈，变量，链表方式组织，是资源分配的单位

2. 线程：共享相同地址环境 ，进程中的一条执行流程 ，线程是cpu调度的单位 ，同进程之间的线程数据传递不用经过内核，抢占式调度，TLB 会刷新

   TLB 是什么？ 页表缓存 

3. 协程 ： 是由用户态实现的，用于 高io下的虚拟化线程，能自行保存所有的变量函数堆栈在堆中，协作式调度 

协程和进程区别 ： 切换代价 ，栈管理（协程是用户栈可动态扩展），阻塞影响：线程可执行其他协程

在内存中 进程和线程的表现都是 task_struct ，通过 clone()标志位实现

# C++八股

c++智能指针 
分为 unique_ptr ，shared_ptr ,weak_ptr;
unique_ptr 独占式指针  是对裸指针的一层包裹 ，不可复制，可以移动，析构时释放

shared_ptr 共享式指针 ，是允许多个·指针共享同一个对象所有权，维护 一个引用计数，共享所有权，引用技术原子操作是线程安全，但修改对象不是线程安全
weak_ptr 弱引用指针，不控制生命周期 ，用 lock 方法转换成 共享指针

# 计网八股 

讲讲 Tcp 和 udp 

tcp 和 udp 都是传输层的协议 ，tcp 是面向连接 的 ，所以每次连接前会有三次握手，udp 是无连接的，没有握手 

tcp 通过确认应答，流量控制，拥塞控制来保证其可靠性，但是 udp 是不可靠的

tcp 是面向字节流，所以 tcp 可能会出现粘包问题，但是 udp 是面向报文的，不会出现粘包问题

故引入 quic ： 在应用层自己实现可靠性 ，udp+自定义加密握手+可靠机制+多路复用

tcp 太保守 ，会产生对头阻塞，连接建立延迟高，尤其是三次握手+tls
