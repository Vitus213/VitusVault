# 面试笔记整理

## 核心原则

1. **默认生成文件，不只在聊天里回复。**
2. **默认生成两份 Markdown 文档。**
3. **格式必须严格参照 `references/` 下的示例文件。**
4. **不要自行发明新章节、新字段、新排版。**
5. **如果用户明确要求改格式，以用户要求为准；否则默认严格对齐 reference。**

## 何时使用

当用户要求以下任一事项时使用此技能：
- 整理面经
- 面后复盘
- 整理面试录音转写
- 根据逐字稿整理面试内容
- 输出面试问题清单 + 分析复盘清单
- 生成二面准备材料

## 何时不使用

- 用户只是要一个普通摘要，没有面试场景
- 用户只是问某一道题怎么答，不需要整理整份材料
- 用户明确只要聊天内简短总结，不要写文件

## 默认输出

除非用户明确另有要求，否则始终生成 **2 份**文档：

### 1. 问题整理文档
用途：沉淀本场面试问了什么。

要求：
- 只做结构化整理，不写评价
- 优先按主题分组
- 每组下按编号列出问题
- 保留反问环节和面试官回复
- **默认不要混入候选人回答原文**，除非用户明确要求

### 2. 分析复盘清单
用途：用于复盘和下一轮准备。

要求：
- 有整体结论
- 有逐题复盘
- 有必背答案清单
- 有复盘优先级
- 有总结
- 逐题复盘必须包含：
  - 问题
  - 我的回答原文
  - 不足
  - 回答关键词
  - 详尽参考回答

## 默认命名

使用以下命名风格：

- `公司名-届别-岗位-轮次-问题整理.md`
- `公司名-届别-岗位-轮次-分析复盘清单.md`

示例：
- `小红书-27届暑期-社区工程-一面-问题整理.md`
- `小红书-27届暑期-社区工程-一面-分析复盘清单.md`

如果信息不全，从材料和上下文中保守推断；命名优先稳定、可读。

## 工作流程

1. 读取面试材料（通常是 `.txt` 转写、录音整理、零散问答）。
2. 识别元数据：公司、届别/实习季、岗位、轮次。
3. 提取面试问题，并按主题归类。
4. 提取候选人关键回答，供分析复盘清单使用。
5. 提取反问环节及面试官回复。
6. 先阅读 `references/` 下对应示例，确认格式。
7. 生成两份 Markdown 文档并写入默认目录。
8. 在聊天中简要报告输出路径。

## 强制格式要求

### 总要求

- **最终格式必须严格参照 reference。**
- 不要擅自增加：基本信息表、评分星级、额外总结块、学习计划天数表等未在 reference 中出现的结构。
- 如果 reference 使用了某种标题层级、分隔线、编号方式、字段顺序，最终输出应保持一致。

### 问题整理文档格式

严格参照：`references/example-questions-document.md`

关键要求：
- 顶部是标题行
- 然后是 `面试问题`
- 正文按主题分组，例如：
  - 一、项目相关
  - 二、操作系统
  - 三、中间件
  - 四、计算机网络
  - 五、算法题
- 每组下按 `1. 2. 3.` 编号列出问题
- 文末保留 `## 反问环节`
- 反问环节格式为：
  - 问题编号
  - 下一行缩进写面试官回复

输出时优先复用这个结构：

```markdown
公司-岗位-轮次-问题整理

面试问题

一、项目相关

1. ...
2. ...

二、操作系统

1. ...
2. ...

---

## 反问环节

1. ...
   - ...
```

### 分析复盘清单格式

严格参照：`references/example-analysis-document.md`

关键要求：
- 顶部使用 `# 标题`
- 包含以下章节，顺序不要改：
  1. `## 整体结论`
  2. `## 逐题复盘`
  3. `## 必背答案清单`
  4. `## 复盘`
  5. `## 总结`

- `整体结论` 使用表格表达
- `逐题复盘` 中每题都必须写：
  - `**问题**：`
  - `**我的回答原文**：`
  - `**不足**：`
  - `**回答关键词**：`
  - `**参考回答**：`
- `参考回答` 必须写得**详尽**，是可以直接用于面试表达的完整答案，不只是提纲
- `复盘` 部分按优先级分组，如 `### P0 / P1 / P2`
- 每个点使用：
  - `**问题方向**`
  - `- 关键词：...`
  - `- 练习方向：...`

输出时优先复用这个结构：

```markdown
# 公司-岗位-轮次-分析复盘清单

## 整体结论

| 维度 | 评价 |
|------|------|
| ... | ... |

---

## 逐题复盘

### 1. ...

**问题**：...

**我的回答原文**：...

**不足**：...

**回答关键词**：...

**参考回答**：
...

---

## 必背答案清单

1. ...
2. ...

---

## 复盘

### P0

**...**
- 关键词：...
- 练习方向：...

---

## 总结
```

## 关于参考回答

`参考回答` 不是关键词提纲，而是可直接复述的完整答案。

写法要求：
- 先正面回答问题本身
- 再补充关键原理、工程做法或面试官可能追问的点
- 语言自然，像面试口述，不要写成教材目录
- 细节要足够支撑高质量表达，但不要堆砌无关背景

## 常见错误

- 只在聊天中回复，不写文件
- 只生成一份文档
- 保存到错误目录
- 问题整理文档没有按主题分组
- 问题整理文档混入评价或复盘内容
- 分析复盘清单没有严格按章节顺序输出
- 逐题复盘漏写任一必需字段
- `参考回答` 写成简短提纲，不够详尽
- `复盘` 没有按优先级整理关键词和练习方向
- 最终文档格式没有严格参照 `references/` 示例
